# Who Goes There? · 谁在那！

> 朝黑暗里喊一声 —— 周围的生物会一个个报出名字、距离和方向。

一个面向科技包玩家的 **实体搜索与定位** 模组。按键一下弹出搜索面板，列出你周围（**所有已加载区块**，
包括区块加载器保活的区域）的全部生物与掉落物，点一下就能定位过去。

- **Minecraft** 1.21.1
- **NeoForge** 21.1+
- **可选**：[JustEnoughCharacters](https://modrinth.com/mod/justenoughcharacters)（拼音搜索）

---

## ✨ 功能

| 功能 | 说明 |
|---|---|
| **一键呼出** | 默认按键 `V`（可在「选项 → 控制」里改绑） |
| **全域扫描** | 扫的是**服务端所有已加载区块**，不只是你身边那一圈 |
| **按距离排序** | 离你最近的排最前，每行显示 名字 · 距离 · 坐标 · 所属模组 |
| **拼音搜索** | 装了 JECh 就能用 `js` / `jiangshi` 搜到「僵尸」（软依赖，没装自动降级） |
| **`@` 模组筛选** | `@apo` 只看 Apotheosis；`@apo 僵尸` 取交集；输入 `@` 有候选浮层 |
| **掉落物聚合** | 同类掉落物合并成一条（`铁锭 ×128`），定位到最近那一堆 |
| **一键定位** | 点选目标 → 发光 10 秒 + 聊天栏坐标消息，**点坐标即填 `/tp` 指令**，另有 `[直接传送]` |
| **全键盘操作** | `↑↓` 选择（浮层开时选候选、关时选结果）· `Enter` 确认 · `Tab` 快捷补全 |

## 📦 安装

1. 装好 NeoForge 1.21.1（21.1 以上均可）
2. 把 `whogoesthere-<版本>.jar` 丢进 `mods/`
3. 可选：把 JustEnoughCharacters 也丢进去，解锁拼音搜索

**多人服务器**：本模组要扫描服务端数据，**服务端也需要安装**。

## 🎮 用法

| 操作 | 效果 |
|---|---|
| `V`（可改绑） | 打开搜索面板 |
| 输入名字 | 实时过滤（中文 / 拼音 / 英文 id 都行） |
| `@模组名` | 只看某个模组的东西，如 `@apo`、`@minecraft` |
| `↑` `↓` | 浮层开着选候选；关着选结果行（自动滚动） |
| `Enter` | 浮层开着=补全候选；关着=确认选中行 |
| `Tab` | 补全第一个候选 |
| 点一行 | 发光定位 + 聊天栏坐标（可点击填 `/tp`） |

## 🔨 构建

```bash
./gradlew build
```

产物在 `build/libs/`。需要 JDK 21。
